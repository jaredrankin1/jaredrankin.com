# Fonts

- **Space Grotesk** (body text) by Florian Karsten, SIL Open Font License 1.1. Embedded in index.html.
- **Coolvetica** (name only) by Typodermic Fonts. Used as fixed vector artwork (outlines), not as a font file, as the Typodermic Desktop EULA allows for logos and images. No font file is distributed.
- Headings use the visitor's own Helvetica / Helvetica Neue / Arial.

## Medieval mode
- **UnifrakturMaguntia** (name and headings in Medieval mode), by j. 'mach' wust and Peter Wiegel. SIL Open Font License 1.1, see UnifrakturMaguntia-OFL.txt. Embedded unmodified as a woff2 from Google Fonts.
- **Grenze Gotisch** (body text in Medieval mode), by Omnibus-Type. SIL Open Font License 1.1, see GrenzeGotisch-OFL.txt. Embedded unmodified as a woff2 from Google Fonts.

## Space mode
- **VT323** (ticker and headings in Space mode), by Peter Hull. SIL Open Font License 1.1, see VT323-OFL.txt. Embedded unmodified as a woff2 from Google Fonts.
